## Limits and remaining requirements

This is the complete currently discovered automated suite, **not V16-01–30 production acceptance**. Storage responses in unit tests and browser APIs in UI tests use fixtures. No real 5 GiB upload, restore drill, capacity load test, credential rotation or production signoff was performed here.

See [the detailed V1.6 gap audit](v16-gap-audit-2026-09-17.md). Highest priorities remain import confirmation and immutable/structural validation, real object promotion and atomic publication visibility, PartUpload/checksum/idempotency, effectivity constraints and audit hash-chain enforcement. New BOM/Revision creation/clone UX, alternate groups, attachment download/scan UI and operational acceptance evidence remain outstanding.

Opaque encrypted attachments remain permitted for authorized download/binding/publication per the user's explicit policy; this is recorded as a policy override, not counted as a missing fail-closed requirement.

Services were updated with `docker compose up -d`; no teardown was performed after health verification.
